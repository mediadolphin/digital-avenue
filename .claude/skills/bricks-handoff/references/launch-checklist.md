# Launch-Checkliste

## Vor dem Umzug
- [ ] Framework-Entscheidung dokumentiert (AT, ACSS, Core Framework)
- [ ] Token-Datei vollständig, keine Literale mehr im Prototyp-CSS
- [ ] Backup der Zielinstallation (z. B. All-in-One WP Migration)
- [ ] URL-Inventar der alten Site mit Redirect-Plan

## Tokens, Schriften, Icons
- [ ] Paletten und Variablen importiert, Report abgehakt
- [ ] Custom Fonts hochgeladen, Google Fonts aktiviert, Fallbacks geprüft
- [ ] Icons als SVG verfügbar, Farbe über currentColor

## Aufbau
- [ ] Theme Styles: Typografie, Buttons, Links, Section-Padding
- [ ] Header und Footer als Templates
- [ ] Global Classes für alle Komponenten der Zuordnungstabelle
- [ ] Seiten nach Prototyp-Struktur, Platzhalter ausgefüllt
- [ ] Formulare: Empfänger, Datenschutzhinweis, Spam-Schutz, Erfolgsmeldung

## Abgleich
- [ ] Screenshots 1440 px und 390 px gegen den Prototyp
- [ ] Mobile Navigation, Dialoge, Tabs, Accordions bedient
- [ ] Bilder: keine Säume, keine Dopplungen, Alt-Texte gesetzt
- [ ] Lighthouse: Performance, Barrierefreiheit, SEO

## Launch
- [ ] Meta-Titel und Descriptions, Schema.org
- [ ] 301-Redirects aktiv und stichprobenartig getestet
- [ ] Sitemap eingereicht, Search Console verbunden
- [ ] Cookie-Banner und eingebettete Dienste geprüft
- [ ] Caching und Bildoptimierung aktiv
